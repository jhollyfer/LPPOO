# 0002 · Saída de dados: para casa

Crie `seunome-casa-NN.ts` nesta pasta (o `NN` é o número do exercício), rode com
`pnpm tsx` e traga funcionando na próxima aula.

1. **Carteirinha.** Mostre na tela o nome da escola, o nome do curso e o nome
   da disciplina, um em cada linha.
2. **Bom dia, grupo da família.** Pergunte o nome de uma pessoa e mostre
   `Bom dia, NOME!`.
3. **Plaquinha da feira.** Pergunte o nome de um produto e o preço. Mostre
   `O produto PRODUTO custa R$ PRECO`.
4. **Arte no terminal.** Desenhe uma caixinha com `console.log`, uma linha por
   vez. Algo assim:

   ```
   +-----------+
   |  CETAM    |
   +-----------+
   ```

5. **Apresentação para a turma.** Pergunte nome, cidade e sonho de profissão.
   Monte um pequeno texto de apresentação usando os três valores numa única
   template string. Capriche, a turma vai ler.
