# 0012 · Comparação de igualdade: para casa

Crie `seunome-casa-NN.ts` nesta pasta (o `NN` é o número do exercício) e rode
com `pnpm tsx`. Teste digitando com e sem letra maiúscula para ver o que muda.

1. **Lista VIP.** Peça o nome do usuário e mostre se ele é igual a `Ana`.
2. **Par ou ímpar?** Peça um número e mostre se o resto da divisão por 2 é
   igual a 0. Se for, o número é par.
3. **Sem frescura com maiúscula.** Peça uma palavra e mostre se ela é igual a
   `typescript`, não importa como a pessoa digitou. Dica: `toLowerCase()` antes
   de comparar.
4. **Os três iguais.** Escreva em comentários a diferença entre `=`, `==` e
   `===`, com um exemplo seu para cada um.
5. **Login.** Peça um usuário e uma senha. Mostre se o usuário é igual a
   `admin` e, numa outra linha, se a senha é igual a `cetam2026`. Depois peça a
   senha de novo, compare as duas senhas digitadas e mostre se a pessoa
   confirmou certo.
